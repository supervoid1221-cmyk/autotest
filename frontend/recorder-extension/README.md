# 自动化测试平台录制扩展

1. 在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录。
3. 打开目标网站的开发者工具，进入“自动化录制器”面板。
4. 选择“UI 操作录制”后点击开始，在业务页面完成点击、输入、下拉和勾选操作。
5. 停止后可预览 Playwright Python 代码；填写平台地址和项目 ID 后，录制器会从该地址已登录的平台页面自动读取 Token 并直接生成智能 UI 用例。未打开或未登录平台时可手工填写 Token。
6. 选择“接口录制”时保留原有 HAR、JSON 导出与接口推送能力。

平台 UI 录制入口：UI 测试 → 智能用例 → 录制用例。密码输入不会保存明文，录制时会转换为 `${password}` 变量。

平台接口录制入口：接口测试 → 接口管理 → 接口录制。认证信息不会写入接口，请在项目的“环境与认证”中维护认证配置。
